Siluetas de avión para la pantalla de Mantenimiento (Finanzas) y el Hangar.

Suelta AQUÍ tus imágenes (las que me pasaste) con estos nombres EXACTOS:

  narrow.png    → 737 / A320 / aviones de pasillo único
  wide.png      → 777 / 787 / A330 / A350 / widebody
  regional.png  → CRJ / Embraer / ATR / regionales

- Formato PNG (un screenshot vale), preferible fondo transparente.
- Si falta alguna, esa categoría usa el dibujo SVG de respaldo.
- La app las carga automáticamente desde /aircraft/<categoria>.png

Tras copiarlas, recarga la app (en dev, basta refrescar; no hace falta recompilar).

Por defecto la app usa siluetas top-view reales embebidas (737-800 y 777-300)
de Peter Lowden (CC-BY 4.0, Wikimedia Commons) con las zonas de mantenimiento
